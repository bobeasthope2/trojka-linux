# Permission from the author

Trojka's 1995 `COPYRIGHT` permits redistribution of the unmodified Unix
sources, allows modification only to fit the code to your own system, and asks
that modifications be mailed to the author rather than redistributed.

This repository was originally built to respect that literally: it shipped only
patches, and downloaded the original tarball at build time.

On **6 November 2026** the author, **Maarten Los**, replied by email — reached
via Edwin, who maintains the FreeBSD `games/trojka` port — and wrote:

> When it comes to the License \*), thanks for informing me of the
> modifications. Please keep the repository up by all means; I'm also fine if
> you want to distribute the ported source directly, if that makes life easier.

So this repository is published with the author's knowledge and explicit
blessing.

## What that does not change

This permission was given to this repository. It is not a relicence of Trojka,
and it does not make the game open source in the OSI or DFSG sense — the
underlying terms still restrict what anyone else may do with the code.

**Do not upload this to Debian, Ubuntu or any other general distribution
archive** without obtaining permission in your own right.
